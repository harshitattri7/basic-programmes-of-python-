# Learning Journey

_Started on 5 November 2025, today is 28 February 2026._

My goal is to become an **AI engineer**. Along the way I practised a sequence
of Python topics, each saved in a notebook or script. The repository now
reflects a step-by-step journey that a viewer can follow from the very first
Python exercises up through data science libraries.

## Course Outline

1. `01_python_basics.py` – simple data types, input/output, operators and a few
   small programs.
2. `02_python_assignments.ipynb` – assorted beginner assignments.
3. `03_conditionals.ipynb` – if/else/elif statements and decision making.
4. `04_loops_patterns.ipynb` – for‑loops and printing patterns.
5. `05_while_loops.ipynb` – while loops, nested loops and related exercises.
6. `06_inheritance_examples.ipynb` – object‑oriented examples on inheritance.
7. `07_numpy_basics.ipynb` – introduction to NumPy arrays and operations.
8. `08_pandas_basics.ipynb` – creating DataFrames and Series with pandas.
9. `09_pandas_assignments.ipynb` – practice tasks using pandas.
10. `10_matplotlib_basics.ipynb` – simple plotting with matplotlib.
11. `11_matplotlib_assignment.ipynb` – additional plotting exercises.
12. `12_seaborn_basics.ipynb` – visualizations using seaborn.
13. `13_module_examples.ipynb` – demonstrations of importing built‑in modules and a custom greeting module (`greetings.py`).

> As you explore the files above you can trace my progress from core Python
> toward data analysis and visualization. Each notebook contains the code I
> wrote while learning each topic.
